# Data licences and attribution

The XTile-S2O-Urban76 record is a collection of components with different source terms. No
single licence covers the complete record.

| Component | Terms |
|---|---|
| Author-created labels, indices, splits, and metadata | CC BY 4.0 |
| Sentinel-1/Sentinel-2 mosaics and processed tiles | Retain the Copernicus Sentinel source terms and the modified-data attribution below |
| Copernicus DEM GLO-30 elevation and derived slope tiles | COP-DEM licence and pass-down obligations included with the archive |

Required Sentinel notice:

> Contains modified Copernicus Sentinel data (2022–2023). Neither the European Commission nor ESA incurs any liability for any use of the Copernicus Sentinel data.

The complete component structure, mandatory COP-DEM notices, intended use, and redistribution
guidance are documented in [docs/DATASET.md](docs/DATASET.md). Preserve each archive component's
included licence file when redistributing it.
